# Governance

Attendra is maintained by [Elegant IT Limited](https://eleganttechbd.com). The maintainers review and merge changes, cut releases, and decide the roadmap in the open, in issues and decision records under `docs/decisions/`.

## How decisions are made

- Day-to-day changes: a maintainer's approval on the pull request.
- Safety-relevant changes (the emergency guardrail, the tool guards, PHI handling, tenancy): two approvals, one of them a maintainer, plus a clinician's review for changes to emergency wording or phrases.
- Direction-setting changes (a new engine, a new data store, the license): a decision record in `docs/decisions/`, open for comment for at least 7 days.

## Becoming a maintainer

Contributors who have landed sustained, high-quality work, especially reviews, can be invited to join as maintainers. The current maintainers are listed in `.github/CODEOWNERS`.

## Commercial offering

Elegant IT Limited plans to offer a hosted service built on this code (signed BAAs, managed numbers, onboarding, support). The open-source project remains complete for a single practice to self-host; features a practice needs to run safely will not be held back for the hosted service.
