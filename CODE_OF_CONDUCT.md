# Code of Conduct

Attendra follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful, assume good intent, and keep the discussion about the work. Harassment, personal attacks and discriminatory language are not acceptable in issues, pull requests, discussions or any other project space.

To report a conduct problem, write to the maintainers through the contact form at [eleganttechbd.com/contact](https://eleganttechbd.com/contact) and name this repository. Reports are read by the maintainers only and handled confidentially. Security issues go through [SECURITY.md](SECURITY.md) instead.
